# 발표자료 조사와 출처

## 공통 적용 기준

사용자가 지정한 산출물 언어와 문체를 우선합니다. 지정이 없으면 기존 문서의 언어·표기 관례를 유지하고, 새 문서는 사용자 요청의 언어를 따릅니다. 대화 언어와 산출물 언어가 다를 수 있습니다. 혼합 언어, 직접 인용, 고유명사는 임의로 번역하지 않습니다. 한국어 개조식·공문 형식을 다른 언어에 강제하지 않습니다. 날짜·소수점·통화·단위는 대상 문서의 지역 관례를 따릅니다. 도구 이름·인자·수식 문법은 번역하지 않고 API 규약을 따릅니다.

아래 수치·배치·호출은 예시입니다. 사용자 지정 내용과 기존 템플릿이 우선하며, 예제의 숫자·날짜·이름을 사실로 복사하지 않습니다. 현재 도구 목록과 인자 설명을 확인한 뒤 제공된 도구만 호출합니다. 운영체제나 Office 연도만으로 지원을 단정하지 않습니다. 완료 검증 도구가 없으면 호출하지 않고 수행 결과·검증 범위·미완료 항목을 답변으로 보고합니다.


## 접근할 수 없는 자료

웹 검색·조회 도구가 현재 목록에 있을 때만 사용합니다. 접근 거부가 반복되는 같은 주소를 계속 재시도하지 말고 공개된 원문, 기관의 다른 공개 자료, 신뢰할 수 있는 재인용 기사를 찾습니다. 과거의 403 응답을 도메인 전체의 영구적인 접근 불가로 일반화하지 않습니다.

## 원문과 재인용 구분

검색 결과 요약은 자료를 찾는 단서이며 수치 확인을 대신하지 않습니다. 원문을 읽지 못했다면 직접 확인했다고 쓰지 않습니다. 기사에서 확인한 값은 「IEA 자료를 인용한 ○○ 기사(날짜, 링크), 원문 미확인」처럼 실제 읽은 자료와 원기관을 구분합니다. 요약만 확인했다면 그 사실을 표시하고 확정 근거로 사용하지 않습니다.

## 수치 검증

단위·기준 연도·지역·대상·집계 방식과 실제 값인지 전망인지 확인합니다. 서로 다른 범위의 값을 합산하거나 비교하지 않습니다. 자체 계산은 사용한 값과 계산식을 남깁니다. 출처를 찾지 못한 수치는 지어내지 않고 제외하거나 미확인으로 표시합니다.

## 슬라이드 표기

수치·그림이 있는 장에 실제 확인한 출처를 적고, 필요한 경우 참고문헌 장에 자료명과 링크를 확장합니다. 직접 인용은 원문과 대조합니다. 사용자 제공 자료는 사용자 제공임을 명시하며 외부 기관의 자료인 것처럼 바꾸지 않습니다.
