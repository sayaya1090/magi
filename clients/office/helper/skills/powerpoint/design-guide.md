# 업무 발표자료 디자인 가이드

## 공통 적용 기준

사용자가 지정한 산출물 언어와 문체를 우선합니다. 지정이 없으면 기존 문서의 언어·표기 관례를 유지하고, 새 문서는 사용자 요청의 언어를 따릅니다. 대화 언어와 산출물 언어가 다를 수 있습니다. 혼합 언어, 직접 인용, 고유명사는 임의로 번역하지 않습니다. 한국어 개조식·공문 형식을 다른 언어에 강제하지 않습니다. 날짜·소수점·통화·단위는 대상 문서의 지역 관례를 따릅니다. 도구 이름·인자·수식 문법은 번역하지 않고 API 규약을 따릅니다.

아래 수치·배치·호출은 예시입니다. 사용자 지정 내용과 기존 템플릿이 우선하며, 예제의 숫자·날짜·이름을 사실로 복사하지 않습니다. 현재 도구 목록과 인자 설명을 확인한 뒤 제공된 도구만 호출합니다. 운영체제나 Office 연도만으로 지원을 단정하지 않습니다. 완료 검증 도구가 없으면 호출하지 않고 수행 결과·검증 범위·미완료 항목을 답변으로 보고합니다.


이 문서는 Magi의 권장 예시입니다. 사용자의 회사 표준이나 Material Design 3의 공식 슬라이드 규격이 아닙니다. 기존 브랜드와 템플릿이 있으면 그것을 따릅니다. 언어 표현과 도구 지원 여부는 `deck-design`을 함께 확인합니다.

## 1. 색과 대비

별도 지정이 없는 밝은 배경 자료에는 제목·강조색 `#1F4E79`, 본문 `#14202E`, 보조 배경 `#E8EFF6` 등을 시작점으로 사용할 수 있습니다. 채움과 글자색의 대비를 함께 확인합니다. 빨강을 모든 감소 수치에 적용하지 않습니다. 비용 감소처럼 긍정적인 변화도 있으므로 의미와 조직의 표기 관례를 따릅니다.

차트 계열색은 테마와 일관되게 사용하되 구분이 어렵다면 지원되는 서식으로 조정합니다. 색만으로 범주를 구분하지 말고 라벨·선 모양 등을 함께 사용합니다.

## 2. 글자 크기

16:9 자료의 시작점은 표지 36~44pt, 장 제목 28~36pt, 본문 20~28pt, 출처 14~18pt입니다. 실제 슬라이드 크기와 투사 환경에 맞춰 조정합니다. 범위 밖의 크기를 금지하지 않습니다. 내용이 많으면 글자를 계속 줄이기보다 요약하거나 장을 나눕니다.

## 3. 여백과 배치

960×540pt 슬라이드라면 좌우 48~64pt 여백을 예시로 삼을 수 있습니다. 다른 크기에 고정 좌표를 그대로 적용하지 않습니다. 기존 자리표시자를 활용하고, 추가 상자는 정렬과 간격을 맞춥니다. 본문과 차트가 같은 좌표를 차지하도록 배치하지 않습니다.

## 4. 도형

강조 상자는 정보 구분에 필요할 때만 사용합니다. 둥근 모서리와 직각 모서리 중 내용과 템플릿에 맞는 것을 고릅니다. 현재 도구가 제공하지 않는 반경·효과 인자를 만들어 호출하지 않습니다.

## 5. 정보량과 출처

한 장에는 주요 메시지를 하나 두고 본문 3~5개 항목을 시작점으로 삼습니다. 표의 행 수나 한 줄의 글자 수를 절대 제한으로 삼지 않습니다. 실제 읽기 어려우면 장을 나누거나 상세 표를 부록으로 옮깁니다.

외부 수치에는 기관·자료명·기준 시점·접근 가능한 링크를 표시합니다. 사용자 제공 수치와 자체 계산은 그 출처나 계산 조건을 적습니다. 단순 순번·날짜까지 외부 출처를 요구하지 않습니다. 확인하지 않은 원문을 직접 읽은 것처럼 인용하지 않습니다(`research`).

## 6. 제목과 문체

한국어 발표자료는 개조식을 기본으로 합니다. 「데이터센터 전력 수요 증가」처럼 핵심이 드러나는 명사구도 적절합니다. 근거가 있을 때만 「5년간 전력 수요 2배 증가」처럼 구체화합니다. 전망이면 「증가 전망」이라고 표시합니다.

사용자가 지정한 제목·인용·표지·목차를 임의로 주장 문장이나 명령형으로 바꾸지 않습니다. 자세한 설명은 발표자 노트에 씁니다.

## 7. 테마

기존 테마는 보존합니다. 새 자료의 디자인을 정하는 범위에서만 테마 변경을 고려합니다. 테마 편집 도구가 없으면 가능한 서식 범위로 작업하고 제한을 보고합니다. 테마 변경이 덱 전체에 적용됐다고 가정하지 말고 실제 결과를 확인합니다.

## 8. 검증

수정한 장의 내용과 시각 결과를 대조합니다. 제목·본문의 크기와 대비, 의도하지 않은 겹침, 출처의 가독성, 한국어 종결 형식의 일관성을 확인합니다. 자동 경고만으로 화면 검증을 대신하지 않습니다. 검증한 범위와 미확인 항목을 구분해 보고합니다.
