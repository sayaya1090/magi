# 시트 설계 — 지켜야 할 것

## 공통 적용 기준

사용자가 지정한 산출물 언어와 문체를 우선합니다. 지정이 없으면 기존 문서의 언어·표기 관례를 유지하고, 새 문서는 사용자 요청의 언어를 따릅니다. 대화 언어와 산출물 언어가 다를 수 있습니다. 혼합 언어, 직접 인용, 고유명사는 임의로 번역하지 않습니다. 한국어 개조식·공문 형식을 다른 언어에 강제하지 않습니다. 날짜·소수점·통화·단위는 대상 문서의 지역 관례를 따릅니다. 도구 이름·인자·수식 문법은 번역하지 않고 API 규약을 따릅니다.

아래 수치·배치·호출은 예시입니다. 사용자 지정 내용과 기존 템플릿이 우선하며, 예제의 숫자·날짜·이름을 사실로 복사하지 않습니다. 현재 도구 목록과 인자 설명을 확인한 뒤 제공된 도구만 호출합니다. 운영체제나 Office 연도만으로 지원을 단정하지 않습니다. 완료 검증 도구가 없으면 호출하지 않고 수행 결과·검증 범위·미완료 항목을 답변으로 보고합니다.


## ✔ 체크리스트

**장(시트)마다:**

| # | 확인 | 지우는 기준 |
|---|---|---|
| 1 | 먼저 읽었다 | `list_sheets` 한 번, 손댈 시트는 `describe_sheet` 한 번. 남의 시트에 쓰기 전에 `read_range` 로 그 자리가 비었는지 봤다 |
| 2 | 머리글이 한 줄 | 첫 행이 열 이름이고 굵게·채우기로 구분된다(`format_range{bold, fill}`) |
| 3 | 숫자는 숫자 | 문자열 "1,234" 가 아니라 1234 를 넣고 `number_format` 으로 보였다. 날짜는 실제 날짜 값인지 되읽어 확인합니다. 문자열에 표시 형식만 적용해도 날짜 값이 되는 것은 아닙니다 |
| 4 | 합계는 수식 | 합계·평균은 값이 아니라 `=SUM(...)` 로 넣어 값이 바뀌면 따라간다 |
| 5 | 폭이 맞다 | 쓰고 나서 `autofit` — #### 이 보이면 안 끝난 것이다 |
| 6 | 눈으로 봤다 | 새로 지은 블록마다 `render_range{max_width: 800}` 한 번. 렌더링이 불가능하면 화면 미검증으로 보고합니다 |

**통합 문서가 끝나면:**

| # | 확인 | 지우는 기준 |
|---|---|---|
| 7 | 머리글 고정 | 데이터가 20행을 넘으면 `freeze_panes{rows:1}` |
| 8 | 표는 표로 | 필터·정렬이 필요한 블록은 `add_table` 로 만들었다(스타일은 테마 것) |
| 9 | 시트별 표로 보고 | `list_sheets` 한 번으로 시트 수·이름·범위를 맞춘다. 전 시트 되읽기는 낭비다 |

## 0. 먼저 읽는다

통합 문서는 **이미 열려 있다.** 파일을 만들거나 올리라고 하지 않는다. `list_sheets` 가 목차고, `describe_sheet` 가 시트
하나의 지도다(표·차트·이름·고정 창·사용 범위). 값은 `read_range` 로 필요한 만큼만 — 큰 시트는 `max_rows` 로 자른다.

## 1. 어디에 쓰나

- 사람이 보고 있는 시트가 「이 시트」다. `sheet` 를 생략하면 그것이다.
- 남의 데이터 옆에 쓸 때는 사용 범위 바로 아래/오른쪽에 한 열·한 행을 띄운다. 겹쳐 쓰면 덮어쓴다 — 답의 `overwrote` 를 본다.
- 새 보고서는 새 시트에(`add_sheet{name}`). 이름은 사람의 어휘(「2분기 요약」).

## 2. 표의 모양

- 첫 행 머리글, 열마다 한 종류의 값, 빈 열·빈 행으로 구역을 가르지 않는다(필터·정렬이 끊긴다).
- 머리글: `format_range{bold:true, fill:"#DDEBF7", align:"Center"}` 정도. 색은 `describe_style` 이 말하는 이 문서의 버릇을 따른다.
- 금액은 `#,##0`, 비율은 `0.0%`, 날짜는 `yyyy-mm-dd`. 문자열로 꾸민 숫자는 계산이 안 된다.
- 합계 행은 굵게, 위 테두리 한 줄(`borders`).

## 3. 수식

- 값이 아니라 수식을 넣는다: `=SUM(C2:C13)`, `=AVERAGE(...)`, `=IF(C2=0,NA(),B2/C2)`.
- 이름을 쓰면 읽기 좋다(`set_name{name:"단가", refers_to:"=Sheet1!$B$1"}`).
- 넣은 뒤 `read_range` 로 되읽어 `#REF!`·`#NAME?` 이 없는지 본다.

## 4. 그림과 차트

- 숫자 셋 이상의 추이·비교는 `add_chart` — 원본 범위에 머리글을 포함한다.
- 차트는 데이터 오른쪽에, 겹치지 않게(`left/top` 을 사용 범위 밖으로).
- 차트를 넣었으면 `render_chart` 로 한 번 본다.

## 4.5 오래 쓸 통장 — 입력·계산·출력을 가른다

사람이 두고두고 숫자를 바꿔 넣을 통장(예산·손익·견적)이면 FAST 표준·정부 모델링 지침이 공통으로 권하는 틀을 따른다.

- **입력 → 계산 → 출력**을 시트(또는 적어도 구역)로 가른다. 흐름은 한 방향 — 출력이 계산을, 계산이 입력을 본다. 거꾸로 잇지 않는다.
- **수식 안에 바뀔 수 있는 숫자를 박지 않는다.** `=B2*1.1` 이 아니라 성장률을 입력 칸에 두고 `=B2*(1+성장률)`(`set_name`).
- **입력 칸은 색으로 표시** — 파란 글자나 옅은 노랑 채우기(`format_range{color:"#0000FF"}` 또는 `fill:"#FFF2CC"`). 색 외에도 입력 항목 라벨을 제공합니다.
- **같은 계산은 한 번만** 하고 나머지는 그 칸을 가리킨다.
- **병합하지 않는다** — 제목을 가운데로 보이고 싶으면 `format_range{align:"CenterAcrossSelection"}`. 병합은 정렬·필터·복사를 깬다.
- **검사 칸**을 둔다: 「합계 검산」 `=SUM(내역)=총계` 가 TRUE 인지. 보고서 위쪽(고정 창 안)에 두면 틀어진 순간 보인다.
- 머리글 행은 고정(`freeze_panes{rows:1}`), 표는 `add_table` 로 — 새 행 추가 후 수식과 참조 범위가 확장됐는지 확인합니다.

## 5. 끝내는 법

완료 검증 도구가 현재 도구 목록에 제공된 경우에만 해당 도구의 설명을 따릅니다. 제공되지 않은 도구는 호출하지 않습니다. 작업 결과는 시트 이름과 범위를 포함해 한 줄씩
(「요약 시트 B2:F14 에 분기별 표」). 조회로 확인한 내용은 수정한 작업과 구분해 보고합니다.
