# 수식 규약

- **수식은 `formulas` 로** 넣는다(`write_range{formulas:[["=SUM(B2:B9)"]]}`). `values` 에 넣어도 "=" 로 시작하면 수식이다.
- **절대 참조**: 채우기 방향으로 고정할 축에 `$` — 단가 셀은 `$B$1`, 행별 값은 `B2`.
- **오류를 감싼다**: 나눗셈은 `=IFERROR(B2/C2, "")`. 찾기는 `XLOOKUP`(2021 이상) 또는 `INDEX/MATCH`.
- **텍스트 숫자**: `read_range` 가 `"1,234"` 같은 문자열을 주면 계산이 안 된다 — 사람에게 알리고, 부탁이 있으면 `VALUE()` 로 옮긴 열을 새로 둔다.
- **이름**: 반복되는 상수·범위는 `set_name`. `read_names` 로 이미 있는 이름을 먼저 본다.
- **유효성**: 입력 시트의 선택지는 `set_validation{validation_kind:"list", values:[…]}`. 숫자 범위는 `whole_number` + `Between`.
- **되읽기**: 수식을 넣은 범위는 `read_range{formulas:true}` 로 되읽어 `#REF!`·`#NAME?`·`#DIV/0!` 이 없는지 본다. 있으면 그 셀 주소를 대고 고친다.
- 순환 참조는 넣지 않는다 — 합계가 제 범위를 포함하는 실수가 흔하다(`=SUM(C2:C14)` 를 C14 에).
- **수식 안에 바뀔 숫자를 박지 않는다** — 세율·성장률·환율은 입력 칸이나 이름으로(`sheet-design` §4.5).

## 자주 쓰는 꼴

| 묻는 것 | 수식 (2행 기준, 아래로 채운다) |
|---|---|
| 조건 합계 「서울 매출 합계」 | `=SUMIFS(C:C, A:A, "서울")` — 조건 여럿이면 `SUMIFS(합, 범위1, 조건1, 범위2, 조건2)` |
| 조건 개수 | `=COUNTIFS(A:A, "서울", B:B, ">=100")` |
| 찾기 「코드로 단가」 | `=XLOOKUP(A2, 단가표[코드], 단가표[단가], "없음")` · 2019 이하면 `=IFERROR(INDEX(단가표[단가], MATCH(A2, 단가표[코드], 0)), "없음")` |
| 증감률 | `=IFERROR(C2/B2-1, "")` + 서식 `0.0%` — 기준이 0 이면 빈칸 |
| 증감(%p) | 비율 칸끼리 `=(C2-B2)*100` + 서식 `0.0"%p"` — 10% → 12% 는 「2.0%p」(「20%」가 아니다) |
| 구성비 | `=C2/SUM($C$2:$C$9)` + `0.0%` — 분모 고정(`$`) |
| 누계 | `=SUM($C$2:C2)` — 시작만 고정 |
| 순위 | `=RANK.EQ(C2, $C$2:$C$9, 0)` (큰 값이 1위) |
| 평균(0 제외) | `=AVERAGEIF(C2:C9, "<>0")` |
| 반올림 | `=ROUND(C2/1000, 0)` — 서식으로 감추지 말고 값이 정말 반올림돼야 할 때만 |
| 날짜에서 월 | `=TEXT(A2, "yyyy-mm")` 또는 `=EOMONTH(A2, 0)` |
| 두 조건 중 하나 | `=IF(OR(B2="", C2=""), "", C2-B2)` |

표(`add_table`)를 쓰면 `표이름[열이름]` 참조가 된다 — 행을 붙여도 범위가 따라가고 읽기도 쉽다.

## 목표값 찾기 — 「얼마가 돼야 ○○이 되나」

Windows 의 Excel 이면 `goal_seek` 이 Excel 의 「목표값 찾기」를 한다.

```
goal_seek {sheet:"손익", cell:"B10", goal:1000, changing:"B2"}
# B10(이익 수식)이 1000 이 되도록 B2(매출)를 바꾼다. 답에 원래 값(changing_was)이 온다.
```

- `cell` 은 **수식 칸**, `changing` 은 **값 칸**(수식이면 거절). 사이가 수식으로 이어져 있어야 한다.
- 입력 칸이 답으로 **바뀐 채 남는다** — 사람이 「계산만」 원했으면 답을 알려 주고 `write_range` 로 원래 값을 되돌린다.
- `found:false` 면 그 값이 나오는 답이 없거나 수렴하지 못한 것이다 — 입력 칸은 마지막 시도값일 수 있으니 되돌린다.

## 예제 — 「지역별 매출 합계랑 비중 넣어 줘」

```
describe_sheet {}                                             # 데이터가 어디 있나 (A1:D200, 머리글 지역·월·매출·비용)
write_range {address:"G1:I1", values:[["지역","매출 합계","비중"]]}
write_range {address:"G2:G5", values:[["서울"],["부산"],["대구"],["광주"]]}
write_range {address:"H2:I5", formulas:[
  ["=SUMIFS($C:$C,$A:$A,G2)","=H2/SUM($H$2:$H$5)"],
  ["=SUMIFS($C:$C,$A:$A,G3)","=H3/SUM($H$2:$H$5)"],
  ["=SUMIFS($C:$C,$A:$A,G4)","=H4/SUM($H$2:$H$5)"],
  ["=SUMIFS($C:$C,$A:$A,G5)","=H5/SUM($H$2:$H$5)"]]}
set_number_format {address:"H2:H5", format:"#,##0"}
set_number_format {address:"I2:I5", format:"0.0%"}
read_range {address:"G1:I5"}                                  # 되읽어 합이 100% 인지
```
