# VS Code 확장 — 사용자 매뉴얼

[↑ 클라이언트 개요](../README.md) · [설계](./DESIGN.ko.md) · [화면 설계](./UI.ko.md) · [플랫폼 규약](./PLATFORM.ko.md) · [무엇을 어디서 재나](./TESTING.ko.md) · [형제: 젯브레인 매뉴얼](../../jetbrains/docs/MANUAL.ko.md)

> **여기 적힌 것은 지금 도는 것뿐이다.** 설계에 있고 아직 안 만든 것은 §8 에 따로 적었다 —
> 매뉴얼이 없는 기능을 설명하면 사람은 자기 설치가 고장 났다고 읽는다.

---

## 1. 시작하기

```
cd clients/vscode
npm install && npx tsc -p .
npx --yes @vscode/vsce package --no-dependencies --allow-missing-repository
code --install-extension magi-0.2.0.vsix --force
```

그다음 **폴더를 연다.** 컴패니언은 워크스페이스의 것이라, 폴더가 없으면 이 확장은 아무것도 안
한다(멀티 루트면 첫 폴더를 본다 — 한 화면에 엔진 둘은 어느 쪽이 답했는지 말할 방법이 없다).

`magi` 실행 파일이 `PATH` 에 있거나 이미 받아 둔 것이 있으면 이 워크스페이스의 컴패니언을
**알아서 띄운다**. 없으면 상태 표시줄이 「not running」이라 말한다.

### 엔진은 창보다 오래 산다

컴패니언은 VS Code 밖의 프로세스다. 창을 닫아도 계속 돌고, 다시 열면 **하던 대화가 그대로**
있다. 같은 워크스페이스를 터미널의 magi 나 웹 콘솔로 열면 **같은 대화**가 보인다.

---

## 2. 어디에 무엇이 있나

| 자리 | 무엇 |
|---|---|
| **아래 패널 `magi`** | 대화. 터미널·문제가 사는 그 자리다 |
| **왼쪽 액티비티 바 `magi`** | 계획과 계기판 |
| **상태 표시줄 왼쪽** | 지금 무엇을 하는가 |

패널이 안 보이면 명령 팔레트(⇧⌘P)에서 **magi: Open the conversation**.

---

## 3. 패널 — 대화

### 3.1 전사 읽는 법

- **사람** — 보낸 글 그대로. 답을 기다리는 동안 왼쪽에 막대가 선다.
- **magi** — 컴패니언의 답.
- **(생각)** — 흐리게, 접힌 채로.
- **도구 한 행** — 이름 한 줄. 결과가 오면 같은 행에 **✓/✗** 가 얹힌다.
- **카운슬** — melchior·balthasar·casper 는 자리 색을 받는다. 그 셋 말고는 색이 없다.
- **오류** — 편집기의 오류 색. 회복된 오류에는 `(recovered)` 가 붙는다. 턴이 끝난 것이 아니라는 뜻이다.

색은 하나도 이 확장이 정하지 않는다. 전부 지금 쓰는 테마의 것이다.

### 3.2 입력줄

**Enter 로 보낸다. Shift+Enter 는 줄바꿈이다.**

입력창 위에 **참조 칩**이 선다 — 우클릭 「Add this code to the conversation」으로 붙인 것들이다.
보내면 함께 나가고 칩은 비워진다. `clear` 로 지울 수도 있다.

### 3.3 승인과 물음

**둘은 다르다.** 컴패니언이 위험한 일을 하려 할 때는 **allow · deny · always** 셋이 서고(그 셋은
magi 자신의 말이라 화면에서 바꾸지 않았다), 컴패니언이 **물을** 때는 선택지 단추와
「answer in the box」가 선다. 뒤엣것을 고르면 입력줄이 **그 물음에 답한다** — 새 턴을 시작하지
않는다.

### 3.4 `@` 로 파일 찾기

입력줄에서 낱말 시작에 `@` 와 두 글자 이상을 치면 컴패니언이 맞는 파일을 찾아 아래에 보여 준다.
이 창이 아는 파일이 아니라 **컴패니언이 닿을 수 있는 파일**이다 — 읽을 쪽이 그쪽이기 때문이다.

### 3.5 컴포저 제안

몇 글자 치고 멈추면 아래에 `Tab: …` 이 뜬다. **Tab** 이 받아들인다.

### 3.6 툴바

**눈 아이콘**은 지금 이 파일 훑어보기, **정지 아이콘**은 도는 턴 세우기. `…` 안에 대화 바꾸기·
모델 고르기·승인 모드가 있다.

---

## 4. 사이드바 — 계획과 계기판

왼쪽 액티비티 바의 magi 아이콘. 다섯 장이 선다: **now · context · jobs · scheduled · fleet**.

⚠ 「이 컴패니언은 그 문을 안 답한다」와 「물어봤는데 비었다」를 **다른 글자로** 그린다. 옛 판의
데몬은 문이 적어서, 빈 자리로 뭉치면 화면이 모르는 것을 아는 척한다.

---

## 5. 상태 표시줄

왼쪽 끝 한 칸. **패널을 접어 둬도 보인다** — 그것이 이 칸이 있는 이유다.

| 보이는 것 | 뜻 |
|---|---|
| `magi: idle` | 붙었고, 노는 중 |
| `$(loading~spin) magi: working · …` | 턴이 도는 중 |
| `magi: waiting on you · …` | **사람의 답을 기다린다** |
| `magi: not running` | 이 워크스페이스에 컴패니언이 없다 |
| `magi: cannot say` | 물어봤는데 답을 못 받았다. **「노는 중」과 다른 말이다** |

⚠ 승인을 기다릴 때도 **배경색이 안 바뀐다.** 글자로 말한다 — 기다리는 것은 오류가 아니다.

## 6. 편집기 안

| 무엇 | 어디 | 켜는 법 |
|---|---|---|
| **인라인 완성** | 커서 자리 회색 글씨 | `magi.complete`(기본 꺼짐). 어느 모델이 답할지는 magi 의 `[autocomplete]` 프로필이 정한다 — 여기 둘째 스위치를 안 뒀다 |
| **타이핑 중 훑어보기** | 손을 멈추면 버퍼를 읽는다 | `magi.lookWhileTyping`(기본 꺼짐 — 멈출 때마다 모델을 부른다) |
| **훑어본 말** | 그 줄 끝 회색 글씨(인레이) | 위와 같음 |
| **파일 전체에 대한 말** | 첫 줄 위 띠 | 위와 같음. **할 말이 없으면 아무것도 안 뜬다** |
| **열린 버퍼 자동 동봉** | (자동) | 항상. 저장 안 한 내용까지 컴패니언이 안다 |

**지금 훑어보기**는 자동이 꺼져 있어도 답한다 — 사람이 눌렀기 때문이다. 할 말이 없으면 상태
표시줄에 그렇게 말한다(조용하면 단추가 안 먹은 것으로 읽힌다).

---

## 7. 진입점

에디터 우클릭의 것들은 **`magi` 하위 메뉴 하나**에 접혀 있다.

| 무엇 | 어디 |
|---|---|
| Add this code to the conversation | 에디터 우클릭 · 탐색기 우클릭(파일 여럿) |
| Ask about this code | 에디터 우클릭 · 코드 액션(💡) |
| Look over this file now | 에디터 우클릭 · 패널 툴바 |
| Which turn wrote this line | 에디터 우클릭 |
| Explain this output | 터미널 우클릭 · **진단이 있는 줄의 코드 액션** |
| Draft a commit message | 소스 제어의 메시지 칸 |

⚠ **「이 출력 설명」의 자리가 젯브레인과 다르다.** 그쪽은 실행 콘솔의 그 줄에서 바로 잡는데,
VS Code 의 터미널은 xterm 이라 선택 영역만 얻을 수 있다. 그래서 **빌드 오류·린트 오류가 사는
자리**(문제 패널의 진단)로 옮겼다. 흉내가 아니라 이 편집기가 그런 말을 세우는 자리다.

**기본 단축키는 없다.** 남의 키를 안 덮으려는 것이라, 원하는 키는 Keyboard Shortcuts 에서
`magi` 로 찾아 묶으면 된다.

---

## 8. 아직 없는 것

- **코어 자동 내려받기.** 지금은 `PATH` 나 이미 받아 둔 것만 쓴다. 창이 여럿일 때 한 번만 받는
  잠금이 따로 만들 값이 있어 미뤘다([설계 §6](./DESIGN.ko.md)).
- **`@` 멘션**(입력창에서 파일 고르기)과 **컴포저 제안**(치다 멈추면 뜨는 힌트).
- **전사에서 옮겨 적기** — 말풍선 단위 선택. 지금은 브라우저의 보통 선택이다.
- **펼친 `edit` 행의 「diff 뷰어로」**.
- **마켓플레이스 게시.** `.vsix` 를 직접 깐다.

---

## 9. 알아두면 좋은 것

- **창을 껐다 켜도 대화는 그대로다.** 원천이 데몬이다.
- **데몬이 답을 물고 늘어지면** 마감에서 연결을 끊고 그렇게 말한다. 조용히 멎지 않는다.
- **컴패니언이 고친 파일은 저절로 다시 읽힌다.** 다만 **고치던 중인 파일은 안 건드린다** —
  화면이 낡은 것보다 손으로 친 것을 잃는 쪽이 나쁘다.
- **같은 폴더를 창 둘에 열면** 대화도 둘이다. 데몬은 하나라 전사는 같지만 입력이 두 자리다.
- **전사를 위로 올려 읽는 중이면 화면이 안 끌려 내려간다.** 맨 아래에 있을 때만 새 행을 따라간다.
- **컴패니언이 없으면 대화 판이 그렇게 말하고 「Start one」 단추를 준다.** 첨부·물어보기도 조용히
  성공하지 않고 같은 것을 묻는다 — 칩만 서고 메시지가 아무 데도 안 가는 것보다 낫다.
- **파일을 안 열었으면** 그 파일이 필요한 명령은 무엇이 필요한지 말한다. 팔레트에서도 그런
  명령은 아예 안 뜬다.
- **컴패니언이 없을 때는 상태 확인을 10초마다 한다**(있을 때는 2초). 없는 소켓을 2초마다 들여다
  보는 것은 아무에게도 아무 말도 안 한다.
