# magi Excel 애드인 — 사용자 매뉴얼

[무엇을 어디서 재나](./TESTING.ko.md) · [구조](./ARCHITECTURE.ko.md) · [도구 하나하나](./TOOLS.ko.md) · [설치](./INSTALL.ko.md) · [헬퍼](../helper/README.md) · [애드인](../addin/README.md) · [파워포인트 판 설계](../../powerpoint/DESIGN.md)

> **이 문서가 무엇인가.** 구현된 기능 전부를 **쓰는 사람의 눈**으로 적는다 — 목적, 사용 방법, 화면.
> 왜 이렇게 설계했는지는 파워포인트 판의 [`DESIGN.md`](../../powerpoint/DESIGN.md)가 말한다 — 엑셀 판은
> 그 설계를 그대로 가져와 손(도구)만 바꿨다.
>
> **도구 61개는 실물 Excel(Mac 16.112.3)에서 2026-09-06 에 전부 돌았다** — MCP 로 하나씩 불러서
> ([`TESTING.ko.md`](./TESTING.ko.md) §5.1). 같은 날 Windows LTSC 2021(16.0.14334)에서는 `install.ps1` 로 깔고 창에서
> 시킨 편집이 셀에 들어갔다([`INSTALL.ko.md`](./INSTALL.ko.md)). 인용·제안 적용·검토 부탁 단추를 사람이 누르며 잰 기록은
> 아직 없다(§9).

## 1. 무엇을 하는 물건인가

Excel 작업창 안에서 magi 컴패니언과 대화하고, **컴패니언이 열려 있는 통합 문서를 직접 읽고 고친다** — 값·수식·
서식·표·차트·조건부 서식·유효성·이름·메모·피벗까지.

- 도구는 **MCP** 로 나간다(`mcp__xl__*` 76개, §6). 컴패니언 쪽에는 새 계약이 없고, 터미널·웹·IntelliJ
  에서 보던 그 대화가 그대로 이어진다.
- **통합 문서를 만지는 손은 애드인이다.** 헬퍼도 데몬도 파일을 안 연다 — Excel 이 열어 둔 문서를 Office.js
  로 고치므로, 저장 안 한 편집과 싸우지 않는다. 셸로 `.xlsx` 를 새로 쓰는 일은 **하지 않는다**(도구 설명이
  모델에게 그렇게 못박는다 — 그것은 아무도 안 보는 파일이다).
- 켜져 있는 컴패니언 중 어디에 붙을지는 대개 스스로 고른다(§4).

셋이 한 줄로 선다:

```
Excel 작업창(애드인)  ←https→  magi office(헬퍼, /xl)  ←unix socket→  magi --daemon  →  모델
     └── 손: Office.js 로 통합 문서를 고친다     └── MCP 서버: 도구 76개를 데몬에 붙인다
```

파워포인트 판과 다른 점 하나: **COM 손이 없다.** Excel 2019·2021·Microsoft 365 는 모두 `ExcelApi 1.7`
이상이라(2021 은 1.14) 작업창이 그대로 손이 된다. 2016 이하는 작업창이 뜨되 편집을 못 하고, 그렇게 말한다(§3.1).

## 2. 설치 — 처음 한 번

### 2.1 필요한 것

| 무엇 | 왜 |
|---|---|
| Excel 2019 이상 (Windows/Mac) 또는 Microsoft 365 | 요구 집합 `ExcelApi 1.7` + `SharedRuntime 1.1`. 찾기·그림은 1.9, 메모는 1.10, 유효성·피벗은 1.8 — 없는 것은 도구가 **이름을 대고 거절한다**. ⚠ **LTSC 2021** 은 1.10 을 ✓ 라 하면서 메모 스레드(`add_comment`·`read_comments`·`resolve_comment`)를 `NotImplemented` 로 거절한다 — 그 판의 한계고 도구가 그렇게 말한다. 같은 판에서 표에 열을 붙이거나 지운 시트의 범위로는 피벗을 못 만든다(원본을 다른 시트로 복사하거나 피벗을 먼저) — [`TESTING.ko.md`](./TESTING.ko.md) §5.10 |
| Go 1.22+ | 헬퍼를 빌드한다 |
| `magi` | 데몬. 통합 문서가 있는 디렉토리(또는 아무 워크스페이스)에서 띄운다 |

### 2.2 헬퍼 빌드

```bash
go build -o magi ./cmd/magi        # 헬퍼는 magi 안에 있다 — `magi office` 가 파워포인트·엑셀·워드 셋을 한 프로세스로 띄운다
```

### 2.3 인증서 — 사람이 신뢰 저장소에 넣는다

첫 기동이 `<config>/office-helper-cert.pem` 을 만든다(키는 `0600`; 세 프로그램 공용이라 하나만 넣는다). Office 작업창은 신뢰 안 되는 https 를 조용히
빈 화면으로 두므로, **그 인증서를 이 계정의 신뢰 저장소에 넣어야 한다.** 방법은 `./magi office -cert-hint` 가 찍는다.

### 2.4 애드인 사이드로드

매니페스트는 `clients/excel/addin/manifest.xml` — `<SourceLocation>` 이 `https://127.0.0.1:3000/xl/taskpane.html` 이고, 헬퍼의
기본 포트도 3001 이다. **둘은 같은 값이어야 한다**(못 잡으면 다른 번호로 안 흘러간다).

- **macOS** — `~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/` 에 `manifest.xml` 을 복사하고
  Excel 을 완전히 끝냈다 다시 연다. 리본 「홈」 오른쪽 끝 **AI Assistant › Magi** 단추가 작업창을 연다.
- **Windows** — `& .\clients\excel\install.ps1` 한 줄이 빌드·인증서·등록·자동 시작까지 한다([`INSTALL.ko.md`](INSTALL.ko.md)
  §0). M365 는 개발자 키, 볼륨 판(LTSC 2021)은 신뢰 카탈로그다 — 파워포인트 판과 **같은 폴더, 같은 키** 하나를 쓴다.
  Excel 2021 은 카탈로그 키가 둘 이상이면 뜰 때 전부 지운다(2026-09-06 실측, INSTALL §3.3). 끝나면 삽입 → 내 추가 기능
  → 공유 폴더 → Magi(AI Assistant) → 추가.

### 2.5 데몬과 헬퍼 띄우기

```bash
magi --daemon          # 통합 문서가 있는 디렉토리에서
./magi office          # 127.0.0.1:3000 — /xl 아래, 애드인 소스는 clients/excel/addin
```

헬퍼는 켜져 있는 컴패니언 명단을 읽고, 애드인이 붙으면 그 컴패니언에 **MCP 서버 `xl`** 로 도구를 단다.
컴패니언이 하나도 없으면 스스로 하나 띄운다(`--permission ask` — 통합 문서를 고치기 전에 **묻는다**).

## 3. 작업창 읽는 법

위에서 아래로: 브랜드 줄 → 대화 → 안내 포스트잇 → 제안 카드 → 입력. 파워포인트 판과 같은 판이고, 다른 것은
인용의 모양(§5)과 안내·제안이 가리키는 곳(시트·범위)뿐이다.

### 3.1 접힌 「지원 API」 줄

작업창이 뜰 때 이 호스트가 `ExcelApi 1.7 / 1.8 / 1.9 / 1.10 / 1.11 / 1.12 / 1.13 / 1.14` 와
`SharedRuntime 1.1` 을 지원하는지 **각각** 잰다. 전부 ✓ 면 줄은 **숨는다** — 꼭 필요할 때만 보는 것이다.
하나라도 빠지면 무엇이 없는지를 펴서 적고, 그때는 그 집합이 필요한 도구가 부를 때 이름을 대고 거절한다.
`1.7` 이 없으면 이 창은 손이 아니고, 브랜드 줄이 「이 Excel 판은 ExcelApi 1.7 이 없어 편집을 못 합니다」
라고 적는다.

### 3.2 브랜드 줄 — 늘 보이는 상태 한 줄

`<컴패니언> · 대화 <이름> · 대화 연결됨 · 문서 N`. 마지막 칸은 헬퍼가 지금 붙들고 있는 통합 문서 수다 —
Excel 창을 둘 띄우면 2 가 된다(창마다 자기 대화를 갖는다).

붙는 과정은 **「준비됐습니다 — 도구 76 개.」** 로 끝난다. 이 수가 곧 증거다: 도구 이름이 데몬에서 되돌아온
것이지 헬퍼의 ack 가 아니다. 이 문장은 첫 대화 줄이 서면 사라진다(위로 같이 스크롤된다).

### 3.3 대화 줄의 종류

사용자 말(오른쪽 정렬, 마크다운), 모델 말(마크다운), **Thinking**(접힌 혼잣말), 도구 줄(사람 말로 — `값 쓰기`,
`시트 목차 읽기`, 61개 전부 라벨이 있다), 권한 물음(§7), 「응답 끝」. 같은 도구 호출이 두 번 그려지는 일은
접힌다.

### 3.4 「새 대화 시작」 · 3.5 「늘 지킬 것」 · 3.6 「가이드」 · 3.7 계획

파워포인트 판 [`MANUAL.ko.md`](../../powerpoint/docs/MANUAL.ko.md) §3.4~§3.7 과 같다. 가이드의 스킬은 엑셀 것
셋이다(`sheet-design`·`formulas`·`charts-and-pivots`, 헬퍼가 컴패니언에 심는다).

### 3.8 「카운슬」 — 꼼꼼함과 속도의 스위치

브랜드 줄 옆 단추. 누르면 **먼저 묻는 판**이 뜬다 — 컴패니언(데몬)이 다시 뜨고, 지금 대화가 새로 시작되고, 같은 데몬에
붙은 다른 창·터미널·IDE·플러그인도 끊겼다 다시 붙는다고. 「다시 띄웁니다」를 누르면 켠 쪽은 컴패니언이 **카운슬로
재기동**하고(끝내기 전 검토), 끈 쪽은 `land` 도구로 스스로 끝낸다.
끈 채 모델이 일을 했다고(또는 하겠다고) 말만 하고 `land` 없이 멈추면 랜딩 플러그인이 「land 로 신고하라」는 넛지를
사용자 메시지로 보낸다(한 대화에 두 번까지) — 작업창은 그 메시지(`⟦landing⟧` 표식)를 **숨긴다.** 인사·되묻기처럼
일을 안 한 턴은 되부르지도 세지도 않는다. 바꾼 것이 정말 없으면 `land{did: ["바꾼 것 없음"]}` 이 받아진다. 켜진
상태는 색이 칠해진다.


### 3.9 프로바이더·모델 고르기와 컨텍스트 띠

**컨텍스트 띠**는 `⋯` 로 편 줄의 맨 위에 선다(늘 보이지는 않는다 — 펼 때 새로 읽고, 편 동안 10초마다) — 지금 대화의
창이 얼마나 찼고 **무엇으로** 찼는지. 띠의 다섯 색은
웹 콘솔과 같은 다섯 조각이고 요청에 실리는 순서다: 시스템(회색) · 도구 목록(보라) · 대화(테마색) · 호출(주황) ·
결과(하늘). 밑줄에 조각마다 토큰 수, 오른쪽에 「30,861 / 200,000 토큰 · 15%」 와 접은 기록. 총량만 보면 사람은
대화를 줄이러 가는데, 이 하네스에서 제일 큰 것은 대개 매 요청에 실리는 도구 목록이다 — 그래서 조각을 그린다.
다섯 조각을 아직 모르는 대화(첫 턴 전)는 띠에 색이 없고, 창을 모르면 퍼센트를 안 짓는다.

띠 옆의 **접기 단추**는 데몬에 압축을 시킨다 — 앞의 대화·호출·결과를 요약으로 바꿔 창을 비운다. 시스템과 도구
목록은 접어도 안 줄므로 그 셋이 0이면 단추가 잠긴다. 누르면 「접는 중」이 뜨고, 끝은 띠가 바뀌는 것으로 본다.
편 동안 10초마다, 그리고 대화가 바뀔 때 다시 읽는다(헬퍼 `/api/context` → 데몬 `context` 문).

**프로바이더·모델**은 `⋯` 로 편 줄의 드롭다운 둘이다 — 아이콘 단추처럼 직접 구현한 M3 exposed dropdown(테두리 필드 +
라벨 + 화살표, 누르면 위로 펴지는 메뉴, 고른 항목에 체크). 펼 때 헬퍼에 묻는다(`/api/models`): 프로바이더는 지금
카탈로그를 답하는 심들(플러그인이 기록한 것 + 지금 쓰는 백엔드 + 전역 설정의 것), 모델은 고른 프로바이더의 목록.
고르면 바로 보내고(`/api/model`), **다음 턴부터**다 — 도는 턴은 그대로 끝난다. 백엔드를 바꾸면 모델 어휘가
바뀌므로 목록을 다시 읽는다. 명단 밖의 주소는 헬퍼가 거절한다 — 이 프로세스가 데몬으로 하여금 프롬프트를 보내게
하는 주소라서(웹 콘솔과 같은 규칙). 지금 것은 목록에 없어도 선다(「명단 밖」이라고 적힌 채).

## 4. 붙는 법 — 대개 아무것도 안 해도 된다

작업창이 뜨면 헬퍼가 켜져 있는 컴패니언 명단을 보고 **하나면 그것에**, 없으면 새로 띄워 붙는다. 여럿이면
고르는 화면이 뜬다 — 워크스페이스 경로·모델·언제 켜졌는지가 보인다. 통합 문서마다 대화가 따로 선다(같은
문서를 다시 열면 같은 대화로 돌아온다 — 문서 안의 `MAGI.BOOK` 설정이 이름표다).

## 5. 말 보내기

입력창에 적고 Enter(줄바꿈은 Shift+Enter). **인용** 단추(또는 범위를 고르고 단추)를 누르면 지금 선택한 범위가
말 앞에 붙는다:

```
[인용] sheet="매출" range=B2:E9 size=8x4
분기	매출	비용	비고
1분기	12000	…
```

- 인용 조각에는 시트·주소·크기·값 표본(최대 12×12, 넘치면 `valuesTruncated=true`)이 실린다. 빈 범위도 인용이다
  — 「(빈 범위)」로 보인다. 값을 못 읽었으면 「(값을 못 읽었습니다)」 — **다른 문장**이다.
- 같은 범위는 두 번 안 붙는다. 조각의 × 로 뗀다.
- **검토 부탁** 단추는 선택한 시트·범위를 문장으로 만들어 준다(「「매출」 시트를 검토해 주세요. 특히 B2:E9」).

## 6. 무엇을 시킬 수 있나 — 말로 하는 것과 그때 도는 도구

말로 시키면 된다. 「매출 시트 B 열을 천 단위로 보여 줘」「분기별 매출 차트를 옆에 그려 줘」「합계가 값으로
박힌 데를 찾아 수식으로 바꿔 줘」. 아래는 그때 모델이 부르는 도구다 — 사람이 도구 이름을 알 필요는 없지만,
권한 물음(§7)에 그 이름이 나온다.

### 6.1 도구 76개

**읽는 것 (19) — 안 물어보고 도는 무리**

| 도구 | 하는 일 |
|---|---|
| `list_sheets` | 목차 — 시트마다 탭 번호·이름·보임·사용 범위·표/차트/피벗 수, 활성 시트 표시. **제일 먼저 부른다** |
| `describe_sheet` | 시트 하나의 모양 — 사용 범위·고정 창·병합·표·차트·피벗·이름·머리글 서식. 값은 안 준다 |
| `read_range` | 범위의 값(2차원)과 수식·표시 형식. 크면 잘라 주고 그렇다고 적는다(`max_rows`) |
| `find` | 글자 찾기 — 시트·주소·값. `limit` |
| `read_table` | 표 하나 — 머리글·행·행 수·스타일 |
| `read_chart` | 차트 하나 — 종류·제목·범례·축 제목·계열·원본 |
| `render_range` | 범위를 **그림으로**(PNG). 제일 비싼 도구 — 서식을 눈으로 확인할 때만 |

### 6.2 「이 시트」가 어느 시트인지 — 되묻지 않게 하는 칸

시트를 안 주면 **활성 시트**다. 번호(`"2"`)도 이름(`"매출"`)도 된다. 주소에 시트 이름을 섞어 쓰면(`매출!B2`)
거절하고 `sheet` 인자로 달라고 한다. 고친 뒤의 답에는 `now.sheet` 가 실려, 다음 호출이 어느 시트인지
되묻지 않는다.

### 6.3 지우는 것도 같은 물음이다 — 되돌리는 길은 스냅숏

`delete_sheet`·`delete_cells`·`clear_range`·`remove_table`·`delete_chart`·`delete_name` 은 다른 쓰기와 같은
권한 물음을 지난다(§7.1 — 물음에 인자가 그려지므로 무엇을 지우는지는 거기서 읽는다). 되돌리는 길은
`snapshot_range` → `restore_range` 뿐이고(값·수식·서식), 시트·차트·이름의 삭제는 되돌릴 손이 없다 — 그래서
`delete_sheet` 의 설명이 「되돌릴 수 없다, 확실치 않으면 먼저 읽어 보라」고 모델에게 말하고, `write_range` 의
설명이 덮어쓰기 전 스냅숏을 권한다.

### 6.4 안내 포스트잇 (`advise`)

모델이 「이건 손대지 않았지만 봐야 한다」를 말하는 자리. 포스트잇에 시트·범위가 실리면 누를 수 있고, 누르면
Excel 이 그 자리로 간다. 시트가 지워졌으면 「이 시트는 이제 없습니다」, 가리킬 곳이 없으면 읽기만 된다.

### 6.5 수정 제안 (`suggest`) — 워드의 주석 자리

모델이 고치지 않고 **제안**만 하는 길. 카드에는 무엇을·왜·어디를·무엇을 할지가 적히고, 「적용」을 누르면 그
손이 돈다(`write_range`·`format_range`·`set_number_format`·`autofit`·`add_conditional_format`·`sort_range`
여섯만 누를 수 있다). 「떼기」는 고치지 않고 카드만 뗀다. 제안은 통합 문서의 설정(`MAGI.FIX.*`)에 살아서 문서를
닫았다 열어도 남는다.

### 6.6 아직 안 되는 것 — 그리고 왜

- **도형·텍스트 상자** — Excel 의 도형 API(1.9)는 있지만 손에 안 달았다. 표·차트·그림으로 충분한지 먼저 본다.
- **슬라이서·스파크라인·매크로** — 안 달았다.
- **통합 문서 저장·다른 이름으로** — Office.js 가 안 준다. 사람이 저장한다.
- **엑셀 밖의 파일 읽기** — 그림 경로 하나뿐이다(헬퍼가 실어 준다).

### 10.1 헬퍼가 다시 뜨면 작업창이 스스로 되살아난다

토큰은 기동마다 새로 나고, 열려 있던 페이지의 토큰은 거부된다. 작업창은 그 거부를 보고 **페이지를 새로 읽어**
새 토큰으로 붙는다(파워포인트 판 §10.1 과 같은 길).
