How to read this

    {{QUARANTINE}} {{WEBTOOLS}}
  • Both sides are rescored by the leaderboard's own rule. tbench.ai's integrity policy defines reward hacking as resolving a task without demonstrating the capability it was meant to measure and sets the consequence at a reward of zero for the trial. On the Claude Code side, the judge in PR #98 flagged twelve trials and three harness-cheating ones were disqualified (code-from-image twice, fix-code-vulnerability once), moving 75.28% to 74.61% — this page uses the adjusted figure. On this side the same scan over all {{N}} adopted trials found none that touched a grader and one that fetched the answer from the internet (regex-chess), rescored to zero. torch-pipeline-parallelism fetched a reference implementation, but the baseline's identical behaviour was not disqualified, so it stands with the reason on its card.
  • k differs. One attempt per task here against five on the leaderboard. Comparing a single good run to an average of five leaves far more room for luck on this side.
  • Timeouts are billed at $0 on both sides. Checked across all 445 leaderboard rows: every one of the 42 AgentTimeoutError rows has a blank cost, and no non-timeout row is blank. The correspondence is exact, so using the same ruler means magi's timed-out runs are zero too. That drops {{NTO}} runs and ${{MDROP}} here — three of them (schemelike-metacircular-eval, dna-assembly, chess-best-move) passed despite being cut, so counting the reward while dropping the cost lands the same way on both sides.
  • So both cost columns are smaller than what was actually spent. ${{MDROP}} is off the books here, and {{CCBLANK}} blank rows are off the leaderboard's. The larger omission is theirs — path-tracing alone has all five trials blank while spending 4.5M to 8.0M tokens each. {{RATIO}}× is a floor, not a ceiling.
