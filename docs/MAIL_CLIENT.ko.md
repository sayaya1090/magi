# IMAP/SMTP 클라이언트

`clients/mail/cmd` 실행 프로그램은 로컬 브라우저 UI를 제공하며, 메일 계정 하나를 공통 Magi 앱 브리지에 연결합니다. 계정 인증정보는 환경변수에서 읽습니다. IMAP·SMTP 어댑터만 이 값을 사용하며 모델 도구 인자에 넣지 않습니다. 실행 변수, TLS 연결 방식, 인수 절차는 [메일 매뉴얼](../clients/mail/README.ko.md)에 정리했습니다.

## 세션과 도구 계약

선택한 메일의 대상 키는 `account/mailbox/uidValidity/uid`입니다. IMAP은 메일함을 읽기 전용으로 열고 UID와 `BODY.PEEK[]<0.2097153>`으로 본문을 읽습니다. 읽기 전에 UIDVALIDITY를 선택 당시의 값과 비교합니다. 목록 조회 뒤 메일이 삭제되거나 메일함이 재생성되면 다른 메일을 대신 반환하지 않고 오류를 알립니다.

`mail_read`에 빈 객체를 전달하면 세션에 연결한 메일을 읽습니다. 선택 인자인 `mailbox`, `uidValidity`, `uid`를 전달하면 동일한 메일을 가리켜야 합니다. 호스트는 세션 대상과 인자가 일치하지 않으면 거부합니다. 응답의 `text`와 MIME `raw` 원문은 별도로 구분합니다. 둘 다 외부의 신뢰하지 않는 자료이므로, 모델은 메일 속 지시를 사용자 요청으로 취급하면 안 됩니다. `mail_draft`는 `to`, `subject`, `body`를 받아 해당 세션의 메모리 초안에 저장하고 `sent:false`를 반환합니다. 메일 발송·삭제 도구는 없습니다.

## 브라우저와 발송

메일 헤더, 해독한 일반 텍스트, MIME 원문, Magi 이벤트는 `textContent`로 DOM에 표시합니다. HTML로 실행하지 않습니다. 다른 메일을 선택하면 이전 SSE 스트림을 취소하고 활성 세션 연결을 비웁니다. 선택 순서 번호로 이전 선택의 늦은 본문 조회·세션 연결 응답을 거부합니다.

SMTP 발송은 인증된 로컬 `/mail/send` HTTP 엔드포인트로만 요청합니다. UI는 확인 대화상자에 초안 전체를 보여주며, 취소하면 발송 요청을 보내지 않습니다. 엔드포인트는 `confirm:true`, 유효한 단일 수신자, 줄바꿈 없는 헤더를 요구합니다. TLS는 필수입니다. 자동 발송 재시도와 보낸 편지함 복사본 저장은 하지 않습니다.

## 현재 검증

단위 테스트 11개와 메일·Magi API를 모의 처리한 Chromium Playwright 테스트가 통과했습니다. 브라우저에서 악성 HTML의 텍스트 표시, 메일별 채팅 요청 귀속, bearer 인증, 발송 취소·확인 후 발송·도구 승인·질문 답변을 검증했습니다. `clients/web/e2e`의 의존성을 설치한 뒤 `node clients/mail/test/ui-playwright.mjs`로 실행합니다.

이 검증에서는 실제 계정에 연결하거나 메일을 발송하지 않았습니다. 현재 UI는 사용자·모델·도구를 구분한 일반 텍스트 대화 행을 제공하며 Markdown은 렌더링하지 않습니다. HTML 전용 본문 처리, 첨부파일, OAuth, 계정 전환, 폴더 탐색, 보낸 편지함 저장은 초기 구현에 포함하지 않았습니다. 실제 계정 인수 절차는 [매뉴얼](../clients/mail/README.ko.md#검증)에 있습니다.

본문 수신 전 RFC822.SIZE를 검사하며, 로컬 TLS IMAP 서버로 초과 크기 거절과 부분 조회를 검증합니다. Playwright는 다른 세션 이벤트 제외, 새 세션·모델 변경·중단, 입력 보존도 확인합니다.

발송 본문은 UTF-8을 quoted-printable로 인코딩하여 8BITMIME를 지원하지 않는 서버에도 전달할 수 있게 합니다. MIME 본문 줄은 76바이트 이내로 접으며, 한국어·긴 문장의 디코딩 왕복을 단위 테스트로 확인합니다. 실제 서버 전달 확인은 별도 인수 항목입니다.
