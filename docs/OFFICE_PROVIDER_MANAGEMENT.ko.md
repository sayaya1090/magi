# Office 프로바이더 관리

[English](OFFICE_PROVIDER_MANAGEMENT.md)

PowerPoint·Word·Excel 작업창의 고급 메뉴에서 **프로바이더 관리**를 제공합니다. 이 컴퓨터의 Magi 전역 설정에 이름 있는 프로바이더 프로필을 저장합니다. 현재 실행 중인 백엔드·모델을 선택하는 기존 드롭다운과는 별도 기능입니다.

화면을 열고 저장된 프로필이나 **새 프로바이더**를 선택합니다. 이름(영문·숫자·하이픈·밑줄), HTTP(S) API 엔드포인트, 모델 ID와 필요한 API 키를 입력해 저장합니다. API 키를 빈칸으로 두면 기존 키를 유지하며, 키 삭제 체크박스를 선택해야 지웁니다. 저장된 키는 화면으로 반환하지 않습니다. 키 입력란은 요청 후와 화면을 닫을 때 비웁니다. 프로필 삭제는 확인 후 수행합니다.

프로필은 인증된 헬퍼 API를 통해 Magi 전역 `config.toml`의 `[llm.profiles.NAME]`에 저장합니다. 여러 필드를 함께 검증한 뒤 한 번에 반영하고 무관한 설정·주석을 유지합니다. 갱신에 실패하면 기존 파일은 그대로입니다. 새 설정 파일은 소유자 전용 권한으로 만들고 기존 파일 권한은 유지합니다. 키는 로컬 설정에 저장하며 이 기능이 암호화 자격 증명 보관함을 추가하는 것은 아닙니다.

저장한 프로필은 데몬을 다음에 시작할 때 사용할 수 있습니다. 기존 대화의 모델을 즉시 바꾸거나 기본 프로바이더를 변경하거나 엔드포인트를 실행하지는 않습니다. 기존 프로바이더 선택 목록은 헬퍼가 발견한 실행 중인 프로바이더를 표시하므로, 프로필 저장만으로 해당 목록에 새 실행 프로바이더가 추가되지는 않습니다. 즉시 반영과 Office 선택 목록에서 프로필을 고르는 기능은 별도 후속 작업입니다. 저장 전에 이 제한을 안내합니다.

## 검증

`go test -race ./clients/office/helper ./internal/config`와 `node clients/office/tools/provider-profiles-test.mjs`를 실행합니다. 브라우저 검증은 PPT·Word·Excel의 동일 관리 모듈에서 좁은 화면, 생성·수정·삭제, 키 유지·삭제, 비밀값 없는 조회와 요청 실패를 확인합니다. 백엔드 테스트는 인증, 잘못된 주소·이름 거절, 키 처리, 영속 저장과 원자적 검증을 확인합니다. 브라우저 모의 실행이 실제 Office 설치 인수 통과를 뜻하지는 않습니다.
