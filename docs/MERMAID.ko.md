# Mermaid로 개발자와 소통하기

[English](MERMAID.md) · [한국어](MERMAID.ko.md) · [문서 지도](README.ko.md)

상태: 구현 참조와 남은 범위. 2026-11-14.

## 목적과 에이전트 지침

답변이 2단계 이상의 관계, 순서, 인과를 설명하면 짧은 설명과 함께 Mermaid 다이어그램을 기본으로 넣습니다. 구성도, 컴포넌트 관계, 요청과 데이터 흐름, 상태 전이, 원인 추적, 작업 순서, 여러 파일에 걸친 변경, 대안 비교가 여기에 해당합니다. 실제 코드 이름을 사용하고 현재 구현과 제안을 구분합니다.

`skill` 도구로 `visual-explanation`을 읽을 수 있습니다. 이 내장 지침은 흐름도·시퀀스·상태·클래스 다이어그램 선택, OOAD의 분석과 설계 구분, GoF 패턴의 책임과 비용 설명을 포함합니다. 개인 교육자료 전체를 배포하지 않습니다. 프로젝트에 같은 이름의 스킬이 있으면 해당 지침을 우선합니다. 별도의 OOAD·아키텍처 스킬이 제공되면 필요한 것만 추가로 읽습니다.

## 도구와 화면

| 환경 | 제공 방식 | 제한 |
|---|---|---|
| JetBrains | 기존 IDE 마크다운 패널에 로컬 Mermaid 스크립트를 주입합니다. | JCEF 마크다운 패널을 사용할 수 없으면 텍스트 폴백입니다. |
| 웹 콘솔 | 마크다운의 Mermaid 코드 블록을 공통 렌더러로 변환합니다. | 브라우저 JavaScript가 필요합니다. |
| VS Code | 웹뷰가 확장에 포함된 렌더러를 로드합니다. | 미완성 코드 펜스는 렌더링하지 않습니다. |
| 독립 실행 로컬 TUI | `mermaid_preview`가 HTML 파일을 저장하고 링크를 반환합니다. | 지원 환경을 확인한 경우에만 도구를 등록합니다. |
| SSH·CI·원격 데몬 연결 TUI | 미리보기 도구를 제공하지 않습니다. | 텍스트로 설명합니다. 원격 데몬에서 사용자 브라우저를 추정하지 않습니다. |

`mermaid` 입력은 `title`, `source`입니다. `source`는 코드 펜스 없는 Mermaid 원본입니다. 도구는 크기와 허용 입력을 확인하며 Mermaid 문법 검증 성공을 주장하지 않습니다. 렌더링 오류는 화면에 표시하고 원본을 보존합니다. 그래픽 클라이언트에는 최종 답변의 Mermaid 코드 블록을 제공합니다.

TUI 답변에는 짧은 설명과 HTML 링크만 제공합니다. 원본은 펼쳐 표시하지 않습니다. 링크를 열면 원본 복사가 가능합니다. 파일은 사용자 캐시의 `magi/diagrams` 아래 저장되며 브라우저를 자동 실행하지 않습니다. 캐시 파일은 사용자 캐시 정리 정책에 따라 제거할 수 있습니다.

기본 모양: 그래픽 클라이언트는 Mermaid `base` 테마에 Material 3 색 롤을 채워 그립니다. 노드는 primary-container 바탕에 on-primary-container 글자를 쓰고 테두리는 없으며, 연결선은 on-surface-variant, 묶음은 surface-container를 씁니다. 롤은 호스트의 `--md-sys-color-*` 값에서 읽습니다. 롤을 정의하지 않는 호스트(VS Code, JetBrains JCEF)는 글자색으로 라이트와 다크를 가려 웹 콘솔 팔레트를 씁니다. 글자는 호스트 서체(`--md-ref-typeface-plain`, 없으면 페이지 서체)로 body-medium 14px입니다. 다이어그램의 `classDef`와 `style` 줄이 우선하고, `%%{init}` 설정은 계속 막습니다. 선택할 수 있는 노드는 Material 3 elevation 그림자로 뜹니다. hover는 레벨 1, 포커스나 선택은 레벨 2, 둘을 함께 받으면 레벨 3입니다. 선택된 노드에는 `aria-pressed`를 붙이고, `prefers-reduced-motion`이면 전환 애니메이션을 하지 않습니다. JetBrains가 SVG를 직접 그린 경우에도 노드, 묶음, 연결선에 같은 롤 색을 덧입힙니다.

## 브라우저 지원 확인

TUI 도구 등록 전과 실행 시 확인합니다. SSH 또는 CI 환경은 제외합니다. macOS는 현재 사용자에게 콘솔 세션이 있고 Safari를 Launch Services에서 찾을 수 있어야 합니다. Linux는 DISPLAY 또는 WAYLAND_DISPLAY, xdg-open, 기본 브라우저 설정, 알려진 브라우저 실행 파일이 필요합니다. Windows TUI 미리보기는 현재 숨깁니다.

이 검사는 환경의 선행 조건을 확인합니다. 실제 창 열기 성공까지 보장하지 않습니다. 따라서 도구 결과는 페이지를 저장했다고만 알리며, 브라우저를 열었다고 보고하지 않습니다. 세 그래픽 클라이언트는 자체 웹 렌더러를 사용하므로 서버의 로컬 브라우저 검사와 무관합니다.

## 인터랙션

맞춤은 작은 차트의 원래 크기를 유지하고, 큰 차트는 사용 가능한 너비와 최대 420픽셀 또는 화면 높이의 55% 안에 맞춥니다. 복잡한 차트는 확대해서 읽을 수 있습니다. 아이콘 버튼에 마우스를 올리거나 키보드 포커스를 주면 설명이 나타납니다.

확대·축소, 화면 맞춤, 원본 복사, 노드 선택과 질문 복사를 제공합니다. 노드를 선택한 뒤 질문을 복사하여 입력창에 붙여 넣을 수 있습니다. 질문을 자동 전송하거나 코드를 실행하지 않습니다. 키보드 Enter·Space로도 노드를 선택합니다. 클립보드 사용이 거부되면 원본을 열어 수동 복사를 안내합니다.

파일·심볼 이동, 연결 경로 강조, 실시간 실행 상태 표시, 입력창으로 직접 질문 전달은 후속 범위입니다. 현재 구현을 이 기능까지 지원한다고 설명해서는 안 됩니다.

`descriptions`는 화면에 보이는 고유한 노드 라벨을 키로 하는 객체입니다. 예를 들어 `{"Agent":"요청을 읽고 답변을 준비합니다."}`처럼 지정합니다. 노드를 선택하면 오른쪽에 설명을 표시하고, 좁은 화면에서는 아래에 표시합니다. 설명이 없으면 없다고 안내합니다. 우클릭 또는 Shift+F10을 누르면 추가 질문을 편집할 수 있습니다. 질문 복사는 차트 원본을 함께 넣으며, 클립보드 사용이 거부되면 직접 선택해 복사할 입력칸을 보여줍니다. 질문은 자동으로 전송하지 않습니다.

화살표가 데이터 이동을 나타내는 흐름도에만 `animate: true`를 지정합니다. 움직이는 점선과 정지용 체크박스를 제공하고, 시스템의 동작 줄이기 설정을 따릅니다. 클래스·상태 다이어그램에는 적용하지 않습니다. 도구는 두 옵션을 Mermaid 원본의 `%% magi-descriptions`, `%% magi-animate` 주석으로 보존합니다. 답변에 차트를 넣을 때 이 주석도 유지해야 합니다. 설명은 일반 텍스트로 최대 100개, 항목당 2000바이트이며 전체 원본의 24,000바이트 제한에 포함됩니다.

## 자산과 경계

공통 구현은 `internal/diagram/web/view.js`와 Mermaid 11.17.2 번들입니다. Go는 이를 임베드하고, VS Code 빌드와 JetBrains 자원 빌드는 같은 파일을 포함합니다. CDN을 호출하지 않습니다. 라이선스는 번들과 함께 보관합니다.

입력은 24,000바이트 이하로 제한합니다. HTML·URL·click 지시문·설정 덮어쓰기는 받지 않습니다. Mermaid strict 모드로 렌더링하고 SVG에서 스크립트·외부 이미지·링크·이벤트 속성을 제거합니다. 모델이 제공한 JavaScript는 실행하지 않습니다. 렌더링은 순서대로 처리하고 최근 32개 원본의 결과를 캐시합니다.

## 검증과 남은 작업

`node internal/diagram/render-test.mjs`는 실제 Chromium에서 렌더링, 확대, 선택, 중복 SVG ID, 문법 오류, 입력 제한, 스트리밍, 좁은 화면, 외부 요청 부재를 확인합니다. Go 테스트는 도구 입력과 SSH 차단, 원격 TUI 노출 방지, 내장 스킬 로드를 확인합니다.

설치된 JetBrains IDE와 VS Code에서의 수동 인수, 모든 Linux 데스크톱 조합과 Windows TUI 지원은 별도 검증 대상입니다. 브라우저가 있다는 사실과 링크를 열 수 있다는 사실을 구분해야 합니다.
